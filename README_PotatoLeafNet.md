## 📌 Project Overview

PotatoLeafNet explores deep-learning-based identification of potato leaf diseases from images. The research aims to support automated plant-disease recognition using computer vision, helping make disease screening more consistent and accessible.

This GitHub repository is intended to document the publication and provide its citation details. It does **not** currently distribute the paper's source code, trained model, dataset, or supplementary experimental files.

## 🎯 Research Objective

The study investigates how a deep-learning model can classify potato leaf images into disease-related categories. Automated image-based classification may help identify visible symptoms and support agricultural decision-making.

The paper focuses on:
- Deep learning for potato leaf disease identification
- Computer vision for agricultural applications
- Classification of potato leaf images
- Addressing class imbalance during model training

## 🧠 Proposed Approach

The paper describes a deep-learning approach called **PotatoLeafNet**. The publication record describes the use of a pretrained DenseNet-based architecture, with an additional transition layer based on DenseNet-201, and a reweighted cross-entropy loss to address imbalanced training data.

At a high level, the workflow is:

```text
Potato Leaf Images
        │
        ▼
Image Preprocessing
        │
        ▼
DenseNet-Based Feature Learning
        │
        ▼
Additional Transition Layer
        │
        ▼
Disease Classification
        │
        ▼
Predicted Leaf Category
```

This diagram is a high-level illustration of the approach, not a reproduction of the paper's complete architecture.

## 📊 Reported Performance

The available publication summary reports **97.2% test accuracy** for the proposed approach.

For the complete experimental setup, dataset composition, class-wise metrics, comparisons, and limitations, please consult the published paper. This README does not add unverified experimental details.
